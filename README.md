# Midnight Private Payroll

[![CI](https://github.com/navin-k24/Private-Payroll/actions/workflows/ci.yml/badge.svg)](https://github.com/navin-k24/Private-Payroll/actions/workflows/ci.yml)

A zero-knowledge confidential payroll compliance and private splits application built on the **Midnight Network**, utilizing **Compact** smart contracts and client-side zk-SNARK provers.

---

## 1. Product Overview: Midnight Private Payroll / Splits

### The Problem
Traditional corporate payroll exposes sensitive financial compensation data to banks, accountants, cloud providers, and on-chain observers. On transparent blockchains, every employee's salary and bonus distribution is publicly visible, violating personal financial privacy and leaking corporate strategy.

### The Solution
**Midnight Private Payroll** enables organizations and employees to prove compensation compliance against public policy thresholds and commit cryptographic split records to the blockchain without ever publishing raw salary numbers. Using Midnight's zero-knowledge Compact contracts, salary figures and blinding nonces are evaluated strictly within client-side witness provers, committing only 256-bit cryptographic hashes on-chain.

---

## 2. Implemented Features

Every feature listed below is fully implemented, tested, and verifiable in this repository:

- **Midnight Lace Wallet Integration:** Native connection and network detection via the Midnight DApp Connector API with automatic account binding and error mapping.
- **Private Salary Verification (`verify_salary`):** Proves that an employee's confidential salary complies with a public ceiling ($0 < \text{salary} \le \text{ceiling}$) without leaking the salary amount.
- **Private Payroll Split Commitments (`record_private_split`):** Registers an anonymized 32-byte cryptographic commitment hash on-chain, proving compliance while protecting split amounts and identities.
- **Duplicate Commitment Protection:** Uses an on-chain `Set<Bytes<32>>` to reject identical split commitments, preventing double-allocation within a payroll cycle.
- **Zero-Knowledge Proof Flow:** Integrates local proof generation (`midnightntwrk/proof-server:8.0.3`) and static ZK key serving (`.prover`, `.verifier`, `.bzkir`) via Next.js public routes.
- **Public Payroll Counters:** Real-time on-chain tracking of `split_count`, `verification_count`, and active `payroll_cycle`.
- **Payroll Cycle Tracking (`advance_payroll_cycle`):** Increments on-chain accounting periods while maintaining historical commitment integrity.
- **Local DevNet Orchestration:** Complete standalone Docker orchestration (`midnight-node`, `indexer-standalone`, `proof-server`) with automated integration tests.
- **Public-Network Compatibility:** Validated on the official **Midnight Preview Testnet** with network mismatch guards and indexer GraphQL synchronization.
- **Multi-Tier CI/CD:** Automated GitHub Actions pipeline validating compilation, 77 automated tests, linting, build, and devnet integration.
- **Isolated Legacy Stellar Prototype:** The baseline Stellar Soroban payment prototype is preserved independently at `/stellar` for historical reference.

## 3. Zero-Knowledge Privacy Model

The application enforces a strict privacy boundary between on-chain public data and confidential off-chain client state:

### Observer Can Directly See (Public On-Chain)
- **Deployed Contract Address:** The unique smart contract address on Midnight.
- **Public Policy Thresholds:** The ceiling argument passed to the circuit (e.g., `maxAllowedSalary = 10000`).
- **Cryptographic Split Commitments:** 32-byte collision-resistant hashes stored in `split_commitments`.
- **Public Split Counter (`split_count`):** Total number of valid splits registered.
- **Public Verification Counter (`verification_count`):** Total number of compliance checks verified.
- **Active Payroll Cycle (`payroll_cycle`):** Current accounting period identifier (`#0`, `#1`, etc.).
- **Circuit Verifier Keys:** Public keys verifying adherence to the Compact contract rules.

### Observer Cannot Directly See (Confidential Off-Chain)
- **Raw Employee Salaries:** The actual numeric compensation value.
- **Private Witness Inputs:** Values ingested through `get_salary_amount()` during zk-SNARK synthesis.
- **Blinding Salts (Nonces):** Random 32-byte nonces ingested through `get_split_nonce()` ensuring cryptographic commitment privacy.
- **Prover Wire Assignments:** Intermediate polynomial evaluation values generated by the proof server.
- **Encrypted Local Storage:** Client-side LevelDB storage holding private state.

## 4. Current Limitation

> **Architecture Limitation:**  
> The current version records and verifies private payroll splits but does not automatically transfer payroll funds to employee addresses. On-chain token balance settlement and automated payouts are roadmap items.

## 6. Quick Start

### Prerequisites
- Node.js 22+
- npm 10+
- Docker & Docker Compose (for local devnet or local proof server)
- Midnight Lace Wallet browser extension

### 1. Install Dependencies
```bash
npm install
```

### 2. Compile Compact Smart Contracts
```bash
npm run contract:compile
```
*(Compiles `contract/contracts/payroll.compact`, runs ZK keygen, and synchronizes verifier/prover keys to `public/zk/`)*

### 3. Start Local Proof Server
```bash
docker run -d --name midnight-proof-server -p 6300:6300 midnightntwrk/proof-server:8.0.3
```
Verify health:
```bash
curl http://localhost:6300/health
# Returns: {"status":"ok","timestamp":"..."}
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
