## 2. On-Chain Lifecycle Evidence

### Phase 1: Contract Deployment
- **Action:** `deployContract(providers, { compiledContract, initialPrivateState: { salaryAmount: 5000n } })`
- **Result:** Contract successfully instantiated on Midnight Preview Testnet.
- **Assigned Contract Address:** `e8c98d59b66ba8986e403eb32a14fbd491515f5f5f01108ca9265d15940e0469`
- **Initial Public Ledger State:**
  - `verification_count`: `0`
  - `split_count`: `0`
  - `payroll_cycle`: `#0`
  - `split_commitments`: `{}` (empty set)

### Phase 2: Record Private Payroll Split (Primary Product Action)
- **Public Policy Input:** `maxAllowedSalary = 10000` (Public threshold)
- **Private Witness Input:** Employee salary supplied strictly off-chain via client witness provider
- **Blinding Salt:** 32-byte cryptographic nonce generated in local secure browser memory
- **Circuit Executed:** `record_private_split`
- **Proof Synthesis:** Local zk-SNARK proof generated by proof server and authorized by Midnight Lace
- **Resulting Public Ledger State:**
  - `split_count`: Incremented from `0` → `1`
  - `split_commitments`: Received collision-resistant 256-bit commitment hash (`Set<Bytes<32>>`)
  - Duplicate Protection: Re-submitting the same commitment is cryptographically blocked by the contract

### Phase 3: Zero-Knowledge Salary Compliance Verification
- **Public Policy Input:** `maxAllowedSalary = 10000` (Public threshold)
- **Private Witness Input:** Employee salary supplied strictly off-chain
- **Circuit Executed:** `verify_salary`
- **Proof Synthesis:** Proves $0 < \text{salary} \le 10000$ without revealing the salary value
- **Resulting Public Ledger State:**
  - `verification_count`: Incremented from `0` → `1`
